과제 10 정렬 알고리즘의 성능 및 안정성 비교

이번 과제에서는 선택 정렬과 버블 정렬 그리고 삽입 정렬을 이용해서 10000개의 데이터를 정렬하고 각 알고리즘의 비교 횟수와 데이터 이동 횟수를 비교했다. 데이터는 두 개의 정수 키로 구성했고 첫 번째 키만을 기준으로 오름차순 정렬하도록 했다. 무작위 데이터는 100회 반복해서 실험하도록 했으며 이미 정렬된 데이터와 역순 데이터 그리고 일부 정렬된 데이터에서도 성능을 비교했다.

1. 무작위 데이터 100회 실험

무작위 데이터는 첫 번째 키와 두 번째 키를 각각 0부터 1000000 사이의 정수로 생성했다. 각 실험에서 같은 데이터를 복사해서 모든 정렬 알고리즘에 사용하도록 했다.

선택 정렬과 일반 버블 정렬은 데이터의 초기 상태와 관계없이 비교 횟수가 49995000회 발생한다. 따라서 100회 실험에서 총 비교 횟수는 4999500000회이고 평균 비교 횟수는 49995000회이다.

삽입 정렬은 무작위 데이터의 순서에 따라 비교 횟수가 달라진다. 서로 다른 값들이 무작위로 배치되었다고 가정하면 평균 비교 횟수는 약 2501만 회 정도로 예상할 수 있다. 데이터 이동 횟수는 약 2502만 회 정도로 예상된다.

일반 버블 정렬은 인접한 두 데이터의 순서를 비교하고 필요한 경우 교환하기 때문에 무작위 데이터에서는 데이터 이동이 많이 발생한다. 조기 종료 버블 정렬은 교환이 한 번도 발생하지 않은 순회에서 종료하지만 무작위 데이터는 대부분의 순회에서 교환이 발생하므로 일반 버블 정렬과 비교 횟수가 크게 차이 나지 않을 것으로 예상된다.

아래 수치는 실제 100회 실행 결과가 아니라 알고리즘의 연산 방식과 무작위 데이터의 특성을 바탕으로 계산하거나 추정한 값이다.

선택 정렬은 총 비교 횟수 약 49억 9950만 회이며 평균 비교 횟수는 49995000회이다.

일반 버블 정렬은 총 비교 횟수 약 49억 9950만 회이며 평균 비교 횟수는 49995000회이다.

조기 종료 버블 정렬은 입력 데이터에 따라 비교 횟수가 달라지며 무작위 데이터에서는 일반 버블 정렬과 큰 차이가 나지 않을 수 있다.

삽입 정렬은 평균 비교 횟수가 약 2500만 회 수준으로 예상되며 선택 정렬과 버블 정렬보다 비교 횟수가 적다.

2. 버블 정렬의 조기 종료 조건 비교

일반 버블 정렬은 데이터가 이미 정렬되어 있어도 정해진 순회를 모두 수행한다. 반면 조기 종료 버블 정렬은 한 번의 순회에서 데이터 교환이 발생하지 않으면 정렬이 완료되었다고 판단하고 종료한다.

이미 정렬된 데이터 10000개를 기준으로 일반 버블 정렬은 49995000회의 비교를 수행하지만 조기 종료 버블 정렬은 첫 번째 순회만 수행하므로 9999회만 비교한다. 두 방식 모두 데이터 교환이 발생하지 않아 이동 횟수는 0회이다.

이 결과를 보면 조기 종료 조건은 이미 정렬된 데이터에서 비교 횟수를 크게 줄여 준다. 하지만 역순 데이터처럼 많은 교환이 필요한 경우에는 대부분의 순회에서 교환이 발생하므로 조기 종료의 효과가 크지 않다.

3. 정렬 알고리즘의 안정성 검증

안정성은 첫 번째 키가 같은 데이터들의 원래 순서가 정렬 후에도 유지되는지를 확인하는 방법으로 검증했다. 각 데이터에 원래 입력 순서를 나타내는 번호를 저장하고 정렬 후 같은 키를 가진 데이터들의 번호를 비교했다.

검증에는 첫 번째 키가 중복되는 데이터를 사용했다. 예를 들어 (5, 100), (3, 200), (5, 300), (2, 400), (3, 500), (5, 600)과 같은 데이터를 사용하면 같은 첫 번째 키를 가진 데이터들의 순서가 유지되는지 확인할 수 있다.

선택 정렬은 불안정 정렬이다. 가장 작은 데이터를 찾아 현재 위치의 데이터와 교환하는 과정에서 같은 키를 가진 데이터들의 원래 순서가 바뀔 수 있기 때문이다.

버블 정렬은 안정 정렬이다. 앞의 데이터의 첫 번째 키가 뒤의 데이터보다 클 때만 교환하도록 구현했기 때문에 첫 번째 키가 같은 데이터끼리는 서로 위치를 바꾸지 않는다.

삽입 정렬에서 비교 조건을 >로 사용하면 안정 정렬이 된다. 현재 데이터보다 키가 큰 데이터만 뒤로 이동시키기 때문에 키가 같은 데이터는 기존 순서를 유지한다.

반대로 >=를 사용하면 키가 같은 데이터도 뒤로 이동한다. 이 때문에 같은 키를 가진 데이터들의 순서가 바뀔 수 있어 불안정 정렬이 된다.

4. 이미 정렬된 데이터에서의 성능

이미 정렬된 데이터에서는 선택 정렬이 49995000회의 비교를 수행하고 데이터 이동은 0회 발생한다. 선택 정렬은 매번 가장 작은 데이터를 찾기 위해 정렬되지 않은 부분을 전부 확인하기 때문이다.

일반 버블 정렬도 49995000회의 비교를 수행하지만 교환이 발생하지 않으므로 이동 횟수는 0회이다. 조기 종료 버블 정렬은 첫 번째 순회에서 교환이 발생하지 않아 9999회의 비교만 수행하고 종료한다.

삽입 정렬은 9999회의 비교를 수행한다. 각 데이터를 임시 변수에 저장하고 최종 위치에 다시 대입하는 방식으로 측정했기 때문에 이동 횟수는 19998회이다. 실제로 배열의 데이터 순서는 바뀌지 않지만 임시 변수 저장과 최종 대입을 이동 횟수에 포함했다.

따라서 이미 정렬된 데이터에서는 조기 종료 버블 정렬과 삽입 정렬이 비교 횟수 측면에서 유리하다.

5. 역순으로 정렬된 데이터에서의 성능

역순 데이터는 첫 번째 키를 기준으로 내림차순 정렬된 상태로 준비했다. 모든 알고리즘은 이 데이터를 오름차순으로 정렬하도록 했다.

선택 정렬은 49995000회의 비교를 수행한다. 역순 데이터에서는 매 순회마다 작은 데이터를 찾아 교환해야 하므로 이동도 많이 발생한다.

일반 버블 정렬과 조기 종료 버블 정렬은 역순 데이터에서 인접한 데이터들을 계속 교환해야 한다. 따라서 두 알고리즘 모두 비교 횟수가 최대치에 가깝고 데이터 이동 횟수도 매우 많다.

삽입 정렬 역시 역순 데이터에서는 현재 데이터를 삽입하기 위해 앞에 있는 데이터들을 대부분 뒤로 이동시켜야 한다. 따라서 비교 횟수와 이동 횟수가 크게 증가한다.

이처럼 역순 데이터에서는 삽입 정렬과 버블 정렬의 장점이 줄어들고 데이터 이동이 많이 발생한다. 선택 정렬은 비교 횟수는 많지만 교환 횟수 자체는 최대 약 9999회이므로 이동 횟수만 비교하면 버블 정렬보다 적을 수 있다.

6. 일부 정렬된 데이터에서의 성능

일부 정렬된 데이터는 먼저 첫 번째 키를 기준으로 정렬한 다음 전체 데이터의 5%에 해당하는 500개의 쌍을 무작위로 선택해 위치를 교환하는 방법으로 만들었다. 이 방법은 인공지능을 활용해 부분 정렬 데이터 생성 방식을 검토하고 그중 일부 원소에만 무작위 교란을 주는 방식을 선택한 것이다.

선택 정렬은 데이터의 초기 상태와 관계없이 49995000회의 비교를 수행한다. 정렬되지 않은 부분에서 가장 작은 데이터를 찾는 과정이 항상 필요하기 때문이다.

일반 버블 정렬은 일부 데이터의 순서가 바뀌어 있어도 정해진 순회를 모두 수행하므로 비교 횟수가 크게 줄어들지 않는다. 조기 종료 버블 정렬은 교환이 없는 순회가 발생하면 종료하지만 일부 데이터가 멀리 이동한 경우에는 여러 번의 순회가 필요할 수 있다.

삽입 정렬은 일부 정렬된 데이터에서 비교 횟수와 이동 횟수가 상대적으로 적게 발생할 수 있다. 이미 정렬된 부분이 많으면 대부분의 데이터가 현재 위치 근처에 삽입되기 때문이다. 다만 무작위로 위치를 교환한 데이터에서는 교란의 정도에 따라 성능이 달라질 수 있다.

7. 입력 데이터 상태에 따른 성능 분석

선택 정렬은 입력 데이터가 무작위인지 정렬되어 있는지와 관계없이 비교 횟수가 일정하다. 매번 정렬되지 않은 부분에서 가장 작은 데이터를 찾아야 하기 때문이다.

버블 정렬은 데이터의 초기 상태에 영향을 많이 받는다. 일반 버블 정렬은 이미 정렬된 데이터에서도 불필요한 비교를 계속 수행하지만 조기 종료 버블 정렬은 교환이 없으면 바로 종료한다. 따라서 이미 정렬된 데이터에서는 조기 종료 조건이 매우 효과적이다.

삽입 정렬은 이미 정렬되어 있거나 일부만 정렬되지 않은 데이터에서 효율적이다. 데이터가 적절한 위치에 가까이 있으면 이동할 데이터가 적기 때문이다. 반대로 역순 데이터에서는 많은 데이터를 한 칸씩 이동시켜야 하므로 성능이 나빠진다.

데이터 이동 횟수에서도 차이가 나타난다. 선택 정렬은 교환이 발생할 때마다 데이터 세 번을 대입하지만 교환 횟수 자체는 비교적 적다. 버블 정렬은 역순에 가까운 데이터에서 교환이 반복되므로 이동 횟수가 많아진다. 삽입 정렬은 데이터를 한 칸씩 이동시키므로 역순 데이터에서는 이동 횟수가 크게 증가한다.

8. 최종 결론

이번 과제를 통해 정렬 알고리즘은 같은 데이터를 정렬하더라도 알고리즘의 방식과 초기 데이터 상태에 따라 성능이 달라진다는 것을 알 수 있었다.

선택 정렬은 비교 횟수가 많지만 데이터 교환 횟수가 적다는 특징이 있다. 버블 정렬은 인접한 데이터끼리 교환하는 방식이며 조기 종료 조건을 추가하면 이미 정렬된 데이터에서 불필요한 비교를 줄일 수 있다. 삽입 정렬은 이미 정렬되어 있거나 일부만 정렬되지 않은 데이터에서 좋은 성능을 보이지만 역순 데이터에서는 많은 이동이 발생한다.

안정성 측면에서는 일반적인 선택 정렬은 불안정 정렬이고 버블 정렬과 >를 사용하는 삽입 정렬은 안정 정렬이다. 삽입 정렬에서 >=를 사용하면 같은 키를 가진 데이터도 이동할 수 있으므로 안정성이 깨질 수 있다.

결론적으로 모든 상황에서 가장 좋은 정렬 알고리즘이 정해져 있는 것은 아니다. 데이터의 초기 상태와 비교 횟수 및 이동 횟수를 함께 고려해서 적절한 알고리즘을 선택하는 것이 중요하다.

참고로 선택 정렬과 일반 버블 정렬의 비교 횟수는 알고리즘 구조를 바탕으로 계산한 값이다. 삽입 정렬의 무작위 데이터 값과 일부 정렬 데이터의 성능은 예상값이며 실제 프로그램의 측정 결과와 다를 수 있다.
