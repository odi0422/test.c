1. 실험 결과

0부터 1000 사이의 숫자를 100번 랜덤으로 생성하고 배열, BST, AVL 트리에 각각 저장하였다. 같은 숫자가 나온 경우에는 중복으로 처리하고 저장하지 않았다.

이번 실행에서는 100번 중 96개의 서로 다른 값이 저장되었고, 4개는 중복이었다.

생성 과정에서 발생한 비교 횟수는 다음과 같다.

배열: 4,659회
BST: 755회
AVL: 518회

저장이 끝난 후의 구조를 확인해 보니 배열의 길이는 96, BST의 높이는 14, AVL 트리의 높이는 8이었다.

2. 탐색 결과 분석

50개의 탐색 대상을 이용해서 세 자료구조를 각각 탐색해 보았다.

결과는 다음과 같다.

순차 탐색: 총 4,597회, 평균 91.94회
BST 탐색: 총 470회, 평균 9.40회
AVL 탐색: 총 341회, 평균 6.82회

순차 탐색의 경우 배열에 없는 숫자를 찾을 때 배열의 처음부터 끝까지 확인해야 하기 때문에 비교 횟수가 크게 나왔다. 실제로 이번 탐색에서도 대부분의 값이 배열에 존재하지 않았고, 이런 경우에는 96개의 값을 전부 비교하게 되었다.

BST는 숫자를 비교하면서 왼쪽이나 오른쪽 중 한쪽으로 이동하기 때문에 배열보다 비교 횟수가 많이 줄어들었다. 하지만 이번 BST의 높이가 14였기 때문에 탐색할 때 경우에 따라 비교 횟수가 14번 정도까지 발생했다.

AVL 트리는 삽입할 때마다 균형을 맞춰주기 때문에 BST보다 높이가 낮게 만들어졌다. 이번 결과에서도 BST의 높이는 14였지만 AVL의 높이는 8이었다. 그 결과 탐색에서도 BST는 평균 9.40회, AVL은 평균 6.82회의 비교가 발생해서 AVL이 더 적은 비교 횟수를 보였다.

자료구조를 만드는 과정에서도 차이가 있었다.

배열은 새로운 값이 들어올 때마다 기존의 값을 처음부터 확인하기 때문에 4,659회의 비교가 발생했다. 반면 BST는 값을 삽입할 위치를 찾아가는 과정에서 필요한 노드만 비교하기 때문에 755회로 줄어들었다.

AVL은 BST와 비슷한 방식으로 삽입 위치를 찾지만 트리의 균형을 유지하면서 삽입하기 때문에 이번 실험에서는 518회의 비교가 발생했다.

AVL의 비교 횟수가 BST보다 적게 나온 것은 이번 데이터의 삽입 과정에서 만들어진 트리 구조와 중복 데이터의 위치에 따른 결과라고 볼 수 있다. AVL의 균형을 맞추는 회전 자체는 숫자 비교 횟수에 포함하지 않았기 때문에 회전 때문에 비교 횟수가 추가된 것은 아니다.


이번 실험에서 가장 눈에 띄었던 부분은 BST와 AVL의 높이 차이였다.

BST 높이: 14
AVL 높이: 8

BST는 데이터를 넣는 순서에 따라 한쪽으로 치우칠 수 있기 때문에 트리의 높이가 높아질 수 있다. 반면 AVL은 삽입할 때 트리의 균형을 계속 맞춰주기 때문에 높이가 크게 높아지지 않는다.

실제로 이번 실험에서도 AVL의 높이가 BST보다 6만큼 낮았고, 탐색 평균 비교 횟수도 BST보다 적게 나왔다.

이번 실험 결과를 비교하면 순차 탐색보다 BST와 AVL을 사용하는 것이 탐색 과정에서는 훨씬 효율적이었다.

특히 AVL은 탐색 평균이 6.82회로 가장 적었고, BST는 9.40회, 순차 탐색은 91.94회였다.

처음에 자료구조를 만드는 비용까지 생각하더라도 탐색을 여러 번 해야 한다면 트리를 사용하는 것이 유리하다고 생각한다. 이번 실험에서는 생성 과정과 탐색 과정을 단순히 더해 보면 다음과 같다.

배열: 4,659 + 4,597 = 9,256회
BST: 755 + 470 = 1,225회
AVL: 518 + 341 = 859회

따라서 이번 실험에서는 생성 비용까지 포함했을 때도 AVL이 가장 적은 비교 횟수를 보였다.

결론

이번 실험을 통해 같은 데이터를 탐색하더라도 자료구조의 형태에 따라 비교 횟수가 크게 달라질 수 있다는 것을 확인했다.

순차 탐색은 구현하기는 간단하지만 데이터가 많아질수록 처음부터 하나씩 확인해야 하는 부담이 커진다. BST는 필요한 방향으로 이동하면서 탐색하기 때문에 순차 탐색보다 훨씬 적은 비교가 필요했다.

그리고 AVL은 BST의 장점을 유지하면서 트리의 균형까지 맞추기 때문에 이번 실험에서는 BST보다 높이가 낮았고 탐색 비교 횟수도 더 적었다.

다만 AVL은 삽입할 때마다 균형을 확인하고 회전하는 과정이 추가된다는 차이가 있다. 그래도 같은 데이터를 여러 번 탐색하는 상황이라면 탐색 과정에서 얻는 이점이 크기 때문에 이번 실험에서는 AVL 트리가 가장 효율적인 방법이었다고 생각한다.
