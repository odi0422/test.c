과제 16. 순차 탐색과 이진 탐색의 성능 비교

1. 실험 환경 및 조건

이번 실험에서는 CSV 파일에 저장된 총 32,033명의 학생 데이터를 사용하였다. 학생의 이름을 기준으로 검색하였으며, 각 학생의 국어, 영어, 수학 점수를 합산하여 총점을 계산하였다.

순차 탐색은 CSV에서 읽어온 원본 배열을 그대로 사용하였고, 이진 탐색은 원본 배열을 복사한 후 학생 이름을 기준으로 퀵 정렬하여 사용하였다.

검색 이름은 기존 학생 데이터에서 가져온 이름과 실제로 존재하지 않는 이름을 함께 사용하였다. 검색 목록은 동일한 순서로 두 탐색 방법에 적용하였으며, K가 증가할 때 기존 검색 목록에 새로운 검색을 추가하였다.

2. 검색 횟수 K를 결정한 이유

검색 횟수는 10회부터 시작하여 50회, 100회, 200회, 500회, 1,000회, 2,000회, 5,000회, 10,000회까지 증가시켰다.

처음에는 검색 횟수가 적을 때 정렬에 필요한 초기 비용이 얼마나 큰 영향을 미치는지 확인하고, 이후 검색 횟수가 많아질수록 이진 탐색의 효율이 얼마나 좋아지는지 비교하기 위해 이러한 구간을 선택하였다.

최대 검색 횟수는 10,000회로 설정하여 검색이 반복될수록 두 방법의 비교 횟수 차이가 어떻게 커지는지 확인하였다.

3. 퀵 정렬의 초기 비용

이진 탐색을 사용하기 위해서는 먼저 학생 이름을 기준으로 배열을 정렬해야 한다.

이번 실험에서 퀵 정렬을 수행한 결과 총 605,388회의 이름 비교가 발생하였다.

이 비용은 검색 횟수와 관계없이 최초 한 번만 발생한다. 따라서 이진 탐색의 전체 비교 횟수에는 퀵 정렬의 비교 횟수 605,388회를 한 번 더해 계산하였다.

5. 실험 결과 분석

실험 결과 검색 횟수가 10회일 때는 순차 탐색이 320,330회로 이진 탐색의 605,569회보다 적은 비교 횟수를 기록하였다.

이는 이진 탐색을 사용하기 위해 먼저 수행해야 하는 퀵 정렬의 초기 비용이 크기 때문이다. 검색 횟수가 적은 상황에서는 정렬에 사용된 비교 횟수를 탐색 과정에서 충분히 절약하지 못하기 때문에 순차 탐색이 더 유리하게 나타났다.

하지만 검색 횟수가 50회로 증가하자 순차 탐색은 1,601,650회, 이진 탐색은 606,288회로 결과가 역전되었다.

즉 이번 실험에서는 K가 10회일 때는 순차 탐색이 유리했지만 K가 50회일 때부터는 퀵 정렬과 이진 탐색을 사용하는 방법이 더 적은 비교 횟수를 기록하였다. 정확한 역전 시점은 추가적인 K 구간 실험이 필요하지만, 적어도 10회와 50회 사이에서 발생한 것을 확인할 수 있었다.

검색 횟수가 1,000회일 때는 순차 탐색이 32,033,000회인 반면 이진 탐색은 623,281회에 그쳤다. 검색 횟수가 10,000회까지 증가했을 때는 두 방법의 차이가 더욱 커졌으며, 순차 탐색은 320,330,000회, 이진 탐색은 784,434회를 기록하였다.

이러한 결과를 통해 순차 탐색은 검색 횟수가 증가할수록 비교 횟수가 빠르게 증가하지만, 이진 탐색은 최초 정렬 비용이 발생하더라도 이후 검색에서는 적은 비교 횟수로 결과를 찾을 수 있다는 것을 알 수 있었다.

6. 두 탐색 방법의 장단점

순차 탐색은 별도의 정렬 과정이 필요하지 않다는 장점이 있다. 따라서 데이터가 적거나 검색 횟수가 적은 경우에는 정렬 비용을 부담하지 않아도 되므로 효율적이다. 하지만 검색할 때마다 배열의 처음부터 끝까지 확인해야 할 수 있기 때문에 검색 횟수가 많아지면 비교 횟수가 크게 증가한다.

반면 퀵 정렬과 이진 탐색은 처음에 정렬하는 과정에서 많은 비교 횟수가 발생한다는 단점이 있다. 하지만 한 번 정렬해 놓으면 이후 검색에서는 이진 탐색을 이용해 빠르게 원하는 데이터를 찾을 수 있다. 따라서 검색을 반복해서 수행하는 상황에서는 순차 탐색보다 유리하다.

이번 실험에서는 검색 횟수가 10회일 때는 순차 탐색이 유리했지만 50회부터는 이진 탐색이 더 적은 비교 횟수를 기록하였다. 특히 검색 횟수가 10,000회일 때 두 방법의 비교 횟수 차이가 매우 크게 나타났다.

결론적으로 데이터의 크기뿐만 아니라 검색을 몇 번 수행하는지도 탐색 방법을 선택하는 데 중요한 요소라고 생각한다. 검색 횟수가 적다면 순차 탐색이 적합할 수 있지만, 같은 데이터를 대상으로 여러 번 검색해야 한다면 최초 정렬 비용을 감수하더라도 퀵 정렬과 이진 탐색을 사용하는 것이 더 효율적이라는 것을 확인할 수 있었다.
