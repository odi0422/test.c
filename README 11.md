
1. 실험 목적

이번 실험에서는 삽입 정렬과 쉘 정렬의 성능을 비교하였다.

데이터 크기를 1000개부터 20000개까지 증가시키면서 각 정렬 알고리즘의 숫자 비교 횟수를 측정하였다. 쉘 정렬은 기본 간격 수열과 크누스 간격 수열을 사용하여 간격에 따른 성능 차이도 확인하였다.

모든 알고리즘은 동일한 무작위 데이터를 사용하였으며 오름차순으로 정렬하였다.

모든 데이터 크기에서 정렬 검증 결과는 PASS로 정상적으로 오름차순 정렬되었다.

3. 데이터 크기에 따른 비교 횟수 변화

실험 결과 데이터 크기가 증가할수록 세 가지 알고리즘 모두 비교 횟수가 증가하였다.

삽입 정렬은 데이터가 1000개일 때 245070회였지만 20000개일 때는 101088881회로 크게 증가하였다. 삽입 정렬은 데이터를 하나씩 앞쪽의 데이터와 비교하면서 위치를 찾기 때문에 데이터가 많아질수록 비교 횟수도 빠르게 증가한다.

반면 쉘 정렬은 큰 간격부터 데이터를 정렬한 후 간격을 줄여 나가기 때문에 삽입 정렬보다 비교 횟수가 훨씬 적었다.

이를 통해 데이터 크기가 커질수록 쉘 정렬이 삽입 정렬보다 효율적이라는 것을 확인할 수 있었다.

4. 삽입 정렬과 쉘 정렬의 성능 차이

모든 데이터 크기에서 쉘 정렬이 삽입 정렬보다 적은 비교 횟수를 기록하였다.

특히 데이터가 20000개일 때 삽입 정렬은 101088881회였지만 쉘 정렬의 크누스 간격 수열은 533673회였다. 약 189배 적은 비교 횟수이다.

이러한 차이는 정렬 방식에서 발생한다. 삽입 정렬은 데이터를 하나씩 비교하면서 위치를 찾아야 하지만 쉘 정렬은 큰 간격으로 먼저 데이터를 정렬하기 때문에 마지막 정렬 과정에서 비교 횟수를 줄일 수 있다.

5. 기본 간격과 크누스 간격 수열의 비교

이번 실험에서는 크누스 간격 수열이 기본 간격 수열보다 모든 데이터 크기에서 적은 비교 횟수를 기록하였다.

데이터가 1000개일 때는 기본 간격이 15143회이고 크누스 간격이 13693회였다. 데이터가 20000개일 때는 각각 608718회와 533673회로 차이가 더 커졌다.

기본 간격은 데이터 크기를 절반씩 줄이는 방식이고 크누스 간격은 3을 곱하고 1을 더하는 규칙으로 간격을 생성한다.

이처럼 간격을 정하는 방식이 다르면 각 단계에서 정렬되는 데이터의 위치와 정도가 달라진다. 이번 실험에서는 크누스 간격 수열이 더 적은 비교 횟수를 기록했기 때문에 더 효율적인 결과를 보였다고 생각한다.

6. 간격 수열이 성능에 영향을 미치는 이유

쉘 정렬은 간격을 이용하여 데이터를 여러 단계에 걸쳐 정렬한다.

처음에는 큰 간격으로 멀리 떨어진 데이터를 비교하고 이후 간격을 점점 줄이면서 정렬한다. 적절한 간격을 사용하면 데이터가 미리 정리되기 때문에 마지막에 간격 1로 정렬할 때 필요한 비교 횟수가 줄어든다.

따라서 어떤 간격 수열을 사용하는지에 따라 전체 비교 횟수가 달라질 수 있다.

이번 실험에서도 크누스 간격 수열이 기본 간격 수열보다 적은 비교 횟수를 기록한 것을 통해 간격 설정이 쉘 정렬의 성능에 영향을 준다는 것을 확인하였다.

7. 결론 및 느낀 점

이번 실험을 통해 삽입 정렬과 쉘 정렬의 성능 차이를 직접 확인할 수 있었다.

삽입 정렬은 구현이 간단하지만 데이터가 많아질수록 비교 횟수가 크게 증가하였다. 반면 쉘 정렬은 여러 간격을 사용하여 데이터를 미리 정렬하기 때문에 비교 횟수가 훨씬 적었다.

또한 쉘 정렬에서도 간격 수열에 따라 성능 차이가 발생하였다. 이번 실험에서는 크누스 간격 수열이 모든 데이터 크기에서 기본 간격 수열보다 적은 비교 횟수를 기록하였다.

이번 과제를 통해 정렬 알고리즘은 단순히 정렬 결과만 확인하는 것이 아니라 비교 횟수를 측정하여 성능을 분석하는 것도 중요하다는 것을 알게 되었다. 특히 간격 수열에 따라서도 성능이 달라질 수 있다는 점이 흥미로웠다.
